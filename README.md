## 📌 Executive Summary

**InsightPilot AI** is a production-grade enterprise decision-intelligence platform that automates the transition from descriptive anomaly detection to prescriptive operational action.

Traditional BI tools reveal **what** happened (e.g. *"Revenue dropped -7.97%"*), but investigating **why** requires weeks of manual cross-dataset correlation across ERP, CRM, WMS, and EDI systems. Meanwhile, generic GenAI chatbots attempt to answer questions by hallucinating numbers without verifiable audit trails.

InsightPilot AI bridges this gap through a defensible architecture: combining **deterministic analytics engines**, **LangGraph multi-agent orchestration**, **SHA-256 cryptographic evidence lineage**, and **capability-aware multi-model AI routing (Groq + Gemini)** with a **calibrated confidence-based abstention guard**.

> ### 🛡️ Foundational Architectural Invariant
> **"Deterministic systems own quantitative truth. LangGraph orchestrates investigation. AI explains grounded facts."**
> 
> *Large Language Models (LLMs) are strictly forbidden from calculating financial metrics, inventing driver rankings, generating speculative evidence citations, or altering recovery simulations. All numbers are computed deterministically from normalized enterprise data.*

## 🔄 The 8-Stage Investigation Lifecycle

InsightPilot AI transitions seamlessly from anomaly detection to executive decision execution across 8 synchronized stages:

```text
┌───────────┐     ┌─────────────────┐     ┌──────────────┐     ┌──────────────┐
│ 1. DETECT │ ──► │ 2. INVESTIGATE  │ ──► │  3. EXPLAIN  │ ──► │   4. PROVE   │
│ KPI Drop  │     │ LangGraph State │     │ Grounded AI  │     │ Evidence SHA │
└─────┬─────┘     └─────────────────┘     └──────────────┘     └──────┬───────┘
      │                                                               │
┌─────▼─────┐     ┌─────────────────┐     ┌──────────────┐     ┌──────▼───────┐
│  8. BRIEF │ ◄── │   7. SIMULATE   │ ◄── │    6. ACT    │ ◄── │  5. DECIDE   │
│ Executive │     │ What-If Sandbox │     │ Action Lever │     │ Decision Gr. │
└───────────┘     └─────────────────┘     └──────────────┘     └──────────────┘
```

1. **DETECT:** Automated KPI anomaly triage triggers when variance exceeds the `-3.0%` materiality threshold.
2. **INVESTIGATE:** An 11-node LangGraph agentic workflow decomposes variance into mutually exclusive causal drivers.
3. **EXPLAIN:** Capability-aware AI (Groq LLaMA 3.3 70B / Google Gemini 2.5 Flash) generates grounded business explanations.
4. **PROVE:** Every finding is substantiated by multi-source empirical evidence carrying SHA-256 cryptographic digests.
5. **DECIDE:** Constructs a dynamic 6-column Decision Graph mapping cause $\to$ evidence $\to$ mechanism $\to$ action $\to$ outcome.
6. **ACT:** Prescribes prioritized operational and strategic intervention levers (e.g. +$484K emergency inventory rebalancing).
7. **SIMULATE:** Real-time deterministic sandbox simulates What-If scenarios (e.g. 79.4% $\to$ 90.0% availability yields +$341,422.91).
8. **BRIEF:** Boardroom-ready executive decision briefing tailored for CFO vs Regional Sales Manager personas.

## 🧠 Core Engineering Highlights

### 1. LangGraph Multi-Agent Orchestration (11-Node Pipeline)
The investigation pipeline ([`ai/langgraph/graph.py`](ai/langgraph/graph.py)) executes an 11-node deterministic state machine:
* `load_kpi_node` $\to$ `calculate_movement_node` $\to$ `identify_drivers_node` $\to$ `retrieve_evidence_node` $\to$ `validate_evidence_node` $\to$ `calculate_confidence_node` $\to$ `confidence_router` (Abstain if score $< 65\%$) $\to$ `prepare_grounding_node` $\to$ `route_ai_capability_node` $\to$ `ai_invocation_node` $\to$ `executive_synthesis_node` $\to$ `recommendations_context_node`.

### 2. Multi-Tier AI Provider Routing & Failover Matrix
The capability-aware AI routing engine ([`ai/orchestration/provider_router.py`](ai/orchestration/provider_router.py)) provides resilient 5-tier failover:
```text
STANDARD REASONING:
[Groq Pool 1: llama-3.3-70b] ──(429/Quota)──► [Groq Pool 2] ──(Unavailable)──► [Gemini Pool 1: gemini-2.5-flash] ──(429)──► [Gemini Pool 2] ──(Outage)──► [Deterministic Fallback]

MULTIMODAL TASKS (Images / Charts):
[Gemini Pool 1] ──(Failover)──► [Gemini Pool 2] ──(Fallback)──► [Deterministic Fallback]
```

### 3. Cryptographic Evidence Lineage & Grounding Validator
* Every evidence record carries a deterministic SHA-256 verification digest (e.g. `sha256:e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`) and 5-layer lineage trace.
* The Post-Generation Grounding Validator inspects LLM JSON responses against the immutable context container and immediately rejects hallucinated citations.

### 4. Deterministic 6-Factor Confidence Engine & Abstention Gate
The confidence score is computed via a strict multi-factor mathematical formula:
$$\text{Score} = 0.25 \cdot \text{Sufficiency} + 0.20 \cdot \text{Quality} + 0.20 \cdot \text{DriverCoverage} + 0.15 \cdot \text{Corroboration} + 0.10 \cdot \text{Lineage} + 0.10 \cdot \text{Consistency}$$
* **Score $\ge 80\%$:** `HIGH` Confidence $\to$ Proceed with full AI synthesis.
* **Score $65\%–79\%$:** `MEDIUM` Confidence $\to$ Proceed with confidence caution banner.
* **Score $< 65\%$:** `LOW` Confidence $\to$ **Mandatory Abstention**. Generative LLM calls are suppressed and a restricted 2-column safe diagnostic graph is rendered.

### 5. Dynamic 6-Column Decision Graph
Synthesizes an interactive causal graph connecting:
* **Col 1 (KPI Anomaly)** $\to$ **Col 2 (Causal Drivers)** $\to$ **Col 3 (Empirical Evidence)** $\to$ **Col 4 (Business Mechanisms)** $\to$ **Col 5 (Action Levers)** $\to$ **Col 6 (Predicted Outcomes)**.

## ⚡ Quick Start & Reproduction Guide

### Prerequisites
* Python 3.11+ (Python 3.13 recommended)
* Node.js 18+ (Node.js 20+ recommended) & npm

### 1. Clone & Configure Environment
```bash
git clone https://github.com/ayus1234/InsighPilotAI.git
cd InsighPilotAI

# Configure environment variables
cp .env.example .env
```

### 2. Backend Setup & Startup
```bash
# Create and activate virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Start FastAPI backend server (Runs on http://localhost:8000)
uvicorn backend.app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 3. Frontend Setup & Startup
```bash
cd frontend/next-app

# Install dependencies
npm install

# Start Next.js development server (Runs on http://localhost:3000)
npm run dev
```

Visit **http://localhost:3000** to interact with the full 7-screen live application.
