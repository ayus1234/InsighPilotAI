## Visual Design Summary

- **Design System:** Dark-mode enterprise glassmorphism (`#0B0F19`, `#161B26`).
- **Typography:** Manrope (Display headers), Inter (Body text), JetBrains Mono (Telemetry & metrics).
- **Core Screens:**
  1. `/` — Executive Command Center
  2. `/root-cause` — Root Cause Diagnosis
  3. `/investigation` — AI Investigation Activity (11-Node LangGraph Timeline)
  4. `/decision-graph` — Decision Graph (6-Column Causal Topology)
  5. `/evidence` — Empirical Evidence Explorer (SHA-256 Hashes & Lineage)
  6. `/recommendations` — Recommendations & What-If Simulation Sandbox
  7. `/briefing` — Executive Decision Briefing (Print & PDF Optimized)
