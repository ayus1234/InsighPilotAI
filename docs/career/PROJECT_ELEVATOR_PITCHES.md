## ⏱️ Pitches by Duration

### 1. 15-Second Pitch (Quick Hook)
> "InsightPilot AI is an enterprise decision-intelligence platform that automates root-cause diagnosis for revenue anomalies by pairing pure Python deterministic math with LangGraph multi-agent orchestration and SHA-256 evidence lineage."

### 2. 30-Second Pitch (Recruiter / Networking)
> "Traditional BI tells executives *that* revenue dropped, but finding *why* takes weeks of manual SQL. Chatbots hallucinate numbers. I built InsightPilot AI to bridge this gap: pure Python calculates deterministic variance ($1.23M drop) and 4-factor root causes (Atlanta stockout 43.2%), while LangGraph orchestrates an 11-node investigation and grounded LLMs synthesize audit-proof executive briefings."

### 3. 60-Second Pitch (Technical Interviewer)
> "InsightPilot AI is a production-grade enterprise decision platform built on a foundational invariant: *Deterministic systems own quantitative truth. LangGraph orchestrates investigation. AI explains grounded facts.* The backend uses FastAPI and pure Python to decompose variances into 100% mutually exclusive drivers and generate SHA-256 cryptographic digests across 9 empirical records. LangGraph manages an 11-node state graph with a mandatory &lt;65% confidence abstention safety gate, routing between Groq LLaMA 3.3 and Gemini with automatic failover. The frontend is a Next.js 14 App Router dashboard with 7 executive screens, verified by 271+ tests."

### 4. 90-Second Pitch (Hiring Manager / Team Lead)
> "I built InsightPilot AI to solve the diagnostic lag and hallucination risk in enterprise decision-making. When a KPI anomaly occurs—like our benchmark $1.23M revenue drop—the system ingests 43,000+ normalized records across ERP, CRM, and WMS. Deterministic Python engines calculate the exact 4-factor root-cause waterfall, identifying an Atlanta DC stockout as the 43.2% primary driver. An 11-node LangGraph state machine orchestrates hypothesis testing, assigns 64-character SHA-256 cryptographic hashes to every piece of evidence, and applies a calibrated confidence model (89% HIGH). If confidence falls below 65%, the AI programmatically abstains. It then models prescriptive actions and What-If inventory elasticity ($32.2K recovery per percentage point). The system delivers sub-second responses via Groq/Gemini routing and is backed by 271 passing automated tests."
