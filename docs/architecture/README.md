# System Architecture Documentation

This directory will contain detailed architectural specifications and design documents for **InsightPilot AI**, including:

- **System Topology & Component Boundaries:** High-level component decomposition separating deterministic analytics, what-if simulations, and LLM reasoning.
- **Data Flow & Sequence Diagrams:** Interaction pipelines from KPI variance detection to driver ranking, evidence attribution, and recommendation generation.
- **State & Metadata Specifications:** Semantic contracts, confidence scoring boundaries, and data freshness policies.
- **Security & Governance:** Persona definition, role-based access control (RBAC), and audit logging.

> *Note: Technical architecture decisions will be documented here as implementation milestones progress.*
