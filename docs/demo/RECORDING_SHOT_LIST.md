## 2. Production Shot Type Categories

- **A-Roll (Presenter Narration):** Studio audio voiceover recorded with clean cardioid microphone (130–145 wpm).
- **B-Roll & Screen Recording:** 1080p60 lossless desktop captures of live Next.js application at 100% zoom.
- **Motion Inserts & Micro-Zooms:** 115% scale zooms on high-density data elements (e.g., SHA-256 hash string, simulation recovery gauge).
