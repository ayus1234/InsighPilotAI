```text
Long Description (200 Words):
Traditional Business Intelligence dashboards inform executives what happened, leaving cross-functional root cause triage to weeks of manual correlation. Generic AI chatbots attempt to explain why, but frequently hallucinate mathematical calculations and lack auditability. 

InsightPilot AI bridges this fundamental enterprise gap through a strict architectural division of labor:
1. Deterministic Analytics: Python analytics engines calculate 100% of mathematical truth from verified relational datasets.
2. Multi-Agent Orchestration: An 11-node LangGraph state machine orchestrates baseline loading, causal driver ranking, evidence gathering, and confidence scoring.
3. Trust & Cryptographic Auditability: Every claim links to empirical evidence records carrying immutable 64-character SHA-256 verification hashes. If confidence falls below 65%, a mandatory safety gate halts generative reasoning.
4. Prescriptive Action & Simulation: A dynamic 6-column Decision Graph connects anomalies to prioritized action levers (+$484K recovery) and real-time What-If simulation (+$341.4K recovery at 90.0% availability).

InsightPilot AI turns passive reporting into actionable, board-level decisions with zero hallucinated figures and measurable ROI.
```

## 5. Responsible AI & Governance

```text
Zero Hallucination Architecture:
The LLM is strictly prohibited from performing mathematical calculations; quantitative facts are pre-calculated deterministically and injected into structured prompt schemas.

Cryptographic Auditability:
All 9 evidence records carry 64-character SHA-256 hash digests with complete 5-layer ETL lineage.

Mandatory Abstention Safety Guard:
If the 6-factor confidence score is below 65%, the system deliberately abstains from generative reasoning, delivering transparent and responsible uncertainty reporting.

Zero Secret Leakage:
100% of credentials, tokens, and API keys are scrubbed from public API responses, Git history, and telemetry logs.
```
